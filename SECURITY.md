# Security Policy

## Reporting a Vulnerability

Si descubres una vulnerabilidad de seguridad en este repositorio, por favor **no** la reportes a través de GitHub Issues. En su lugar, por favor envía un email a tu email de contacto con los siguientes detalles:

- Descripción de la vulnerabilidad
- Pasos para reproducirla (si es posible)
- Impacto potencial
- Tu nombre de contacto (opcional)

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Security Updates

Este es un proyecto portfolio personal. Los problemas de seguridad serán tratados con alta prioridad y se publicará un parche lo antes posible.

## Best Practices

Para mantener este proyecto seguro:

- Mantén tus dependencias actualizadas
- Reporta cualquier problema de seguridad responsablemente
- Revisa el código antes de ejecutarlo

## Contacto

Para preguntas de seguridad, por favor contacta directamente al propietario del repositorio.
